# ClassIsland Android 技术细节

## 悬浮窗实现
- 使用 WindowManager.TYPE_APPLICATION_OVERLAY (API 26+)
- 自定义 View 通过 Canvas.onDraw() 实时渲染课表
- 每30秒自动刷新，支持拖拽移动
- 所有样式（颜色/大小/边框/圆角/透明度）均可配置

## 数据持久化
- 设置和课表均存储为 JSON 文件在 app files 目录
- SettingsManager / ProfileService 单例管理
- Gson 序列化，线程安全

## 多语言
- values/strings.xml → English (默认)
- values-zh/strings.xml → 中文
- values-ja/strings.xml → 日本語

## GPU 加速
- GpuAccelerator.kt 封装 OpenGL ES 和 Rust JNI
- Rust 原生库通过 JNI 提供渲染加速
- 无原生库时自动回退到软件渲染

## 权限
- SYSTEM_ALERT_WINDOW: 悬浮窗
- POST_NOTIFICATIONS: 通知 (API 33+)
- FOREGROUND_SERVICE: 前台服务常驻
