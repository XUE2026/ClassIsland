# 项目技术细节

## 项目结构

### ClassIsland.Android/
```
├── app/
│   ├── build.gradle.kts          # Android 应用配置
│   └── src/main/
│       ├── AndroidManifest.xml   # 权限、Activity、Service
│       ├── java/com/classisland/android/
│       │   ├── MainActivity.kt           # 主活动
│       │   ├── ClassIslandApp.kt         # Application 类
│       │   ├── model/                     # 数据模型
│       │   │   └── AppSettings.kt        # 应用设置
│       │   ├── service/
│       │   │   ├── OverlayService.kt     # 悬浮窗服务
│       │   │   └── ProfileService.kt     # 课表服务
│       │   ├── overlay/
│       │   │   └── OverlayView.kt        # 悬浮窗视图
│       │   ├── rust/
│       │   │   └── GpuAccelerator.kt     # GPU 加速 JNI 桥接
│       │   ├── settings/
│       │   │   └── SettingsManager.kt    # 设置管理器
│       │   └── ui/
│       │       ├── theme/                # 主题
│       │       ├── screens/              # 页面
│       │       └── components/           # 组件
│       └── res/                          # 多语言资源
│           ├── values/                   # 英语
│           ├── values-zh/                # 中文
│           └── values-ja/                # 日语
├── build.gradle.kts              # 根构建文件
├── settings.gradle.kts           # 项目设置
└── gradle/wrapper/               # Gradle Wrapper
```

## 构建命令

### 本地调试构建
```bash
cd ClassIsland.Android
echo "sdk.dir=$ANDROID_HOME" > local.properties
./gradlew assembleDebug
```

### GitHub Actions 构建
- 推送至 `android_environment` 分支自动触发
- 手动触发: GitHub Actions → Build Android APK → Run workflow
