# 项目技术细节

## Android 项目结构

```
ClassIsland.Android/
├── app/
│   ├── build.gradle.kts      # App 模块构建配置
│   ├── proguard-rules.pro    # ProGuard 混淆规则
│   └── src/main/
│       ├── AndroidManifest.xml
│       ├── cpp/
│       │   ├── CMakeLists.txt          # CMake 配置
│       │   └── libs/                   # Rust 编译产物（4个ABI）
│       ├── java/com/classisland/android/
│       │   ├── ClassIslandApp.kt       # Application 类
│       │   ├── MainActivity.kt         # 主 Activity
│       │   ├── model/                  # 数据模型
│       │   ├── overlay/                # 悬浮窗功能
│       │   ├── service/                # 后台服务
│       │   ├── ui/                     # UI 界面（Jetpack Compose）
│       │   └── util/                   # 工具类
│       └── res/                        # 资源文件
├── rust_core/
│   ├── Cargo.toml                      # Rust 项目配置
│   ├── build_android.sh               # Rust 构建脚本
│   └── src/
├── build.gradle.kts                    # 根项目 Gradle 配置
├── settings.gradle.kts                 # 项目设置
├── gradle.properties                   # Gradle 属性
└── gradlew                             # Gradle Wrapper
```

## 构建技术栈

- **构建系统**: Gradle 8.x + Android Gradle Plugin 8.2.2
- **语言**: Kotlin 1.9.22 + Jetpack Compose (BOM 2024.01.00)
- **原生代码**: Rust (通过 JNI 调用)
- **Min SDK**: 29 (Android 10)
- **Target SDK**: 34 (Android 14)
- **Compile SDK**: 34

## Rust 原生库架构

| ABI | Rust Target |
|-----|-------------|
| arm64-v8a | aarch64-linux-android |
| armeabi-v7a | armv7-linux-androideabi |
| x86_64 | x86_64-linux-android |
| x86 | i686-linux-android |

## 签名配置（Release）

Release 构建需要以下 secrets：
- `ANDROID_KEYSTORE_BASE64` - 签名密钥库的 Base64 编码
- `ANDROID_KEYSTORE_PASSWORD` - 密钥库密码
- `ANDROID_KEY_ALIAS` - 密钥别名
- `ANDROID_KEY_PASSWORD` - 密钥密码

## GitHub Actions 缓存策略

- **Rust**: 缓存 `~/.cargo/registry`、`~/.cargo/git`、`rust_core/target`
- **Gradle**: 缓存 `~/.gradle/caches`、`~/.gradle/wrapper`、`.gradle` 目录
