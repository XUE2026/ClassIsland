# ClassIsland Android 项目说明

## 技术栈
- 主要语言: Kotlin 100%
- 性能优化: Rust (JNI/NDK)
- UI: Jetpack Compose + Material3
- 最低支持: Android 10 (API 29)
- 构建: Gradle 8.5, AGP 8.2.2

## 核心功能
- 悬浮窗课表：前台服务常驻，Canvas 绘制，可拖拽，自定义颜色/大小/位置/样式
- 课表管理：科目编辑，时间布局，JSON 导入导出
- 多语言：中文、English、日本語
- GPU 加速：OpenGL ES + Rust 原生库
- 版权：首次启动弹窗，标注原作者和 XUE2026

## 项目结构
```
ClassIsland.Android/
├── app/src/main/java/com/classisland/android/
│   ├── model/         # 数据模型
│   ├── overlay/       # 悬浮窗服务
│   ├── service/       # 后台服务
│   ├── ui/            # UI 界面
│   ├── rust/          # GPU 加速
│   └── util/          # 工具类
├── rust_core/         # Rust 原生代码
└── app/src/main/res/  # 资源文件 (values/values-zh/values-ja)
```
