# 项目说明

## ClassIsland Android 移植

### 项目概述
将 ClassIsland（桌面端课表软件）完整移植到 Android 平台，生成 APK。

### 目标平台
- 最低 Android 10 (API 29)
- 目标 Android 14 (API 34)

### 主要功能
- 课表展示（悬浮窗模式）
- 完整的设置页面
- 多语言支持（中文/英语/日语）
- GPU 加速支持
- 首次启动许可协议

### 原作者 & 修改者
- 原作者: ClassIsland 团队
- 修改者: XUE2026
- GitHub 项目: https://github.com/XUE2026/ClassIsland

### 技术栈
- Kotlin (主语言)
- Jetpack Compose + Material3
- Android Gradle Plugin 8.2.2
- Gradle 8.5
