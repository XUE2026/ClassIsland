# 项目说明

## 项目名称
ClassIsland.Android - Android 平台 APK 构建

## 项目概述
ClassIsland 是一个桌面课程表/信息岛应用，本项目为其 Android 平台的 APK 构建配置。

## GitHub Actions 工作流

### build-android-apk.yml
构建 Android APK 的 GitHub Actions 工作流。

**触发条件**：
- Push 到 `android**` 分支
- PR 到 `android**` 分支
- 手动触发（workflow_dispatch）

**工作流包含两个 Job**：
1. **build-rust**: 编译 Rust 原生库（4 个 ABI 架构）
2. **build-apk**: 构建 Android APK（debug/release）

**Rust 原生库**：
- 源码位于 `ClassIsland.Android/rust_core/`
- 使用 `cargo-ndk` 编译
- 输出 `libclassisland_rust.so`，通过 JNI 与 Android 交互

**构建产物**：
- Debug APK：未签名，自动上传为 artifact
- Release APK：需要 secrets 配置签名密钥，支持自动发布到 GitHub Release
